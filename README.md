# Logic – Python Practice & Mini Projects

A collection of Python programs focused on logic building, games, and useful utilities.

## 📁 Projects

### Games
- **Number Guessing Game** – Guess the random number with high/low feedback
- **Rock Paper Scissors**
- **Snake Water Gun**
- **Quiz Game** – Computer hardware quiz with scoring
- **Choose Your Own Adventure**
- **Pig Game**

### Utilities
- **Password Generator** – Generate passwords with letters, digits, or symbols
- **Password Manager** – Securely store and view passwords using Fernet encryption

### Practice Sets
Multiple practice files covering core Python concepts.
